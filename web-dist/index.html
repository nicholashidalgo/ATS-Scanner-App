TalentScan

Resume versus job description, scored the way an ATS would read it.

Keyword match, semantic match, gap analysis

Paste or upload a resume and a job description. The scanner returns an overall match score, five sub-scores, a requirement-by-requirement evidence table, and the edits that move the number. Nothing is stored.

What you get

Three outputs,
one pass

01

Analysis modes

Keyword mode counts exact-term coverage the way a legacy parser does. Semantic mode uses embeddings to credit equivalent phrasing. Pick one per run and compare.

02

Actionable report

Overall match score, sub-scores for skills, responsibilities, tooling, credentials, and ATS readability, plus ranked recommendations, strengths, and gaps.

03

Export and share

Download the report as a PDF, copy the raw JSON, or hand the JSON to an LLM for guided resume edits against the specific gaps found.
